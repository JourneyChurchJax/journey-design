# Hand marks

Marker strokes for graphics: a circle, an underline, an arrow, and the long line that runs across a carousel.

- These are drawn in code to look like marker. They are **stand-ins**. When Adam's real handwriting is scanned (black marker on white paper, photographed flat), save it here as transparent PNGs and use those instead.
- Written words ("see you there", "Much love, Adam") must come from the real scan. Until then, mockups use a stand-in pen font and say so.
- Red marks count as the one red thing on a graphic. White marks are for photos.
