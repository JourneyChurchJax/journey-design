# Sunday photos

One folder per Sunday (`YYYY-MM-DD`), holding the photos from that Sunday's photo post on social. Every photo here has already been posted publicly by Journey Church, so it is cleared for future promotions.

- Copied every Monday from OneDrive (`Photo Assets/<year>/Sunday Services/<date>/`, where Journey Command files each Sunday post) by `tools/sync-sunday-photos.sh` in the Social Media folder.
- Resized to 2048px on the long side, JPEG. The full-size originals stay in OneDrive.
- Use the same color treatment as every Journey photo. Favor hands, posture and the room over faces, and pick shots without children up front unless a parent has said yes.
