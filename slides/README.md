# Stage &amp; series slides

Six sample boards, each at real output pixels and scaled to fit. They are the seven-piece series package minus the square and story feed cards, which live in the Command kit.

| File | Size | What it is |
|---|---|---|
| `title-slide.html` | 1920 × 1080 | The series title board |
| `sermon-title-slide.html` | 1920 × 1080 | Weekly sermon title over the dimmed collage |
| `scripture-slide.html` | 1920 × 1080 | Scripture in Newsreader |
| `lyric-slide.html` | 1920 × 1080 | Worship lyrics, four lines max |
| `lower-third-slide.html` | 1920 × 1080 | Name plate over a photo |
| `announce-slide.html` | 1080 × 1080 | The feed post that launches a series |

All six are recreations of the boards on `brand/index.html` and `brand/sermon-series/index.html`. The type fitter in the title and announce slides is the inline script from those pages.

Stage minimums: lyrics 100px, Scripture 80px, labels 30px. Action-safe 96px, title-safe 120px. Build at 3840 × 2160 for a 4K wall.
