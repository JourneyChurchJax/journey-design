# Project instructions

## Filing new designs
Before building any new design (graphic, slide, story, logo, etc.), ask Adam whether it is a **Ministry**, **Project**, **Series**, or **Event** — unless he already said so. File it in the matching folder:
- Ministry → `ministries/<slug>/` (card group "Ministry · <Name>")
- Project → Read brand.md (the full brand guide) and readme.md before designing or writing anything for Journey Church.`projects/<slug>/` (card group "Project · <Name>") 
- Series → `series/<slug>/` (card group "Series · <Name>")
- Event → `events/<slug>/` (card group "Event · <Name>")

Also confirm which files should be added to the design system as cards; don't add extras he didn't ask for.
